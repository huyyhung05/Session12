Lưu ý Word Auto TOC:
Các file SRS đã chèn trường Auto TOC và dùng Heading Styles. Khi mở trong Microsoft Word, nếu số trang chưa cập nhật, bấm vào mục lục -> Update Table -> Update entire table (hoặc Ctrl+A rồi F9).
